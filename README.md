# rukh-ui

Web UI for [Rukh](https://github.com/w3hc/rukh) — build your own AI with personalized contexts.

Live at **[rukh.it](https://rukh.it)**.

## Install

```bash
pnpm i
```

## Run

```bash
pnpm dev
```

## Build

```bash
pnpm build
```
